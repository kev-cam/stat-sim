## Metering validation (before quoting ANY VACASK energy) — PRE-STATED
Closed-form case: series RC discharge, C=1pF pre-charged to 1V through R=1kΩ
(tau=1ns), simulate 10ns. Analytic: E_R = 0.5*C*V0^2*(1-exp(-20)) =
0.499999999*pJ ≈ 0.5 pJ; also I(0)=1mA, v_c(1ns)=V0/e.
Meter in BOTH engines with the committed cap-integrator idiom (B-source into
1F cap; the decks' CX*/BX*/RX* pattern), NOT Xyce .measure INTEGRAL (known
11-44% under-report; we re-document its error here as a side check).
PASS per engine: |E_R,metered - analytic| <= 0.5%. VACASK energies are
quotable only if VACASK passes; else VACASK is time/voltage-only.

## AMENDMENT 1 (2026-09-29 ~23:05 PDT, before any accepted gate result)
The FIRST gate attempt (22:47-22:48 PDT) is INVALID and its artifacts were
wiped: every deck ran in ~1 s against Xyce's BUILT-IN NMOS (level-1 class)
because PyMS auto-load failed SILENTLY. Root cause chain, all MEASURED:
1. All committed QAL decks carry `.hdl` on LINE 1, which Xyce swallows as the
   title line on BOTH binaries (probe: line-1 .hdl with bad path is ignored;
   line-2 errors loudly). PSP103 actually loads via the PyMS AUTO-LOAD
   registry (model card `nmos level=103` miss-path) — on the local box too
   (XYCE_PYMS_AUTO_DEBUG shows "auto-loading ... for (M, 103)").
2. The PyMS shell compile links `-lXyceLib`, but CMake names the product
   libxyce.so; the LOCAL build tree carries a HAND-PLACED libXyceLib.so
   (mtime Sep 26 19:02) that Phase-1 did not know to replicate. On P620a the
   link failed ("cannot find -lXyceLib") — loud under explicit .hdl, SILENT
   under auto-load, which falls back to built-in NMOS. Fix applied on P620a:
   cp -p libxyce.so -> libXyceLib.so inside /usr/local/src/xyce-build/src.
   (Toolchain defect worth fixing upstream: auto-load compile failure is
   silent; the model then runs wrong physics with only "parameter ignored"
   warnings.)
3. Fresh-cache semantics now cover BOTH caches: PYMS_VAE_CACHE (vae math .so)
   and PYMS_CACHE (device shells; ambient default /tmp/pyms_hdl_cache also
   removed). v1's single-cache assumption was insufficient.
Invalid v1 numbers, kept ONLY as the silent-wrong exemplar (P620A-XYCE-
BUILTIN-FALLBACK, never to be mixed): VBEND 6.760437e-01, VBPK 7.408536e-01,
EOUTA 1.785587e-14 — "close but wrong" (VBPK off 0.46%): the failure mode the
digit gate exists to catch, and it caught it.
Registration proof required from v2 logs: ".HDL: compiled and registered
PSP103VA" and device table "M level 103 (PSP103VA MOSFET)".
